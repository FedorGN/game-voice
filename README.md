# game-voice

## Записи рояля

В тренировке используются записи Salamander Grand Piano V3 Александра Хольма. Фрагменты укорочены, сведены в моно и плавно затушены в конце. [Salamander Grand Piano V3](https://github.com/sfzinstruments/SalamanderGrandPiano) · [Исходные файлы Tone.js](https://github.com/Tonejs/audio/tree/master/salamander) · [CC BY 3.0](https://creativecommons.org/licenses/by/3.0/)
